# Phase 1 — قاموس البيانات وعقود مصدر الحقيقة

## الغرض

تثبت هذه الوثيقة الحدود التي يجب ألا تتجاوزها أي ميزة في FAMILY. الهدف هو منع الخلط بين الرقم المالي المنشور في الدفتر وبين السعر الخارجي أو الإسقاط التحليلي أو الحالة التشغيلية.

## طبقات البيانات

| الطبقة | التعريف | المصدر المسموح | هل تُنشئ قيدًا؟ |
|---|---|---|---|
| `ledger_fact` | حدث مالي منشور وقيد يومية متوازن وسطور مدينة/دائنة | `financialEvents`, `journalEntries`, `journalLines` | نعم، عبر خدمة نشر مالية صريحة ومصرح بها فقط |
| `derived_projection` | رصيد أو P&L أو Cash Flow أو Net Worth مشتق من الدفتر | Queries ومحركات الحساب | لا |
| `external_market_data` | سعر أو FX قادم من مزود خارجي مع المصدر والوقت والحالة | `priceQuotes`, `fxRates`, Yahoo/Frankfurter | لا |
| `valuation_snapshot` | لقطة تقييم مؤرخة تستخدم للتقرير أو المقارنة | ستُستكمل في مرحلة التقييم | لا، إلا عبر مسار مالي يدوي معتمد إذا تطلب الأمر |
| `operational_metadata` | تدقيق، حالة بريد، حالة مهمة، جودة بيانات، تفضيلات | جداول التشغيل والتدقيق والإشعارات | لا |

## قواعد ملزمة

يظل `ledger_fact` المصدر الوحيد للحركات المالية والأرصدة الدفترية. لا يجوز لـYahoo Finance أو Heartbeat أو إشارات الاستثمار أو السيناريوهات أو AI Advisor إنشاء صفقة أو قيد أو إعادة تقييم تلقائية.

كل Projection يجب أن يكون قابلًا لإعادة الحساب من السجلات المنشورة، وأن يعلن عن نقص البيانات أو تقادم السعر أو غياب سعر الصرف بدل تحويل النقص إلى صفر صامت.

كل External Market Data يجب أن يحفظ على الأقل الأداة أو الزوج، المصدر، وقت السعر، وقت الإدخال، الحالة (`live`, `delayed`, `last_known`, `manual`) وأي تحويل عملة أو وحدة.

كل Valuation Snapshot رسمي يجب أن يكون مؤرخًا، ويذكر مجموعة البيانات التي بُني عليها، وحالة التقادم، والعملة الأساسية، وما إذا كان صالحًا للتقرير الرسمي أو للعرض المرجعي فقط.

## قاموس المصطلحات المالية

| المصطلح | التعريف التشغيلي |
|---|---|
| Transaction | طلب أو حدث مالي يصف الحركة التجارية |
| Journal Entry | قيد يومية واحد مرتبط بالحدث |
| Journal Line | سطر مدين أو دائن داخل القيد |
| Balance | مجموع سطور الحساب بعد تطبيق اتجاهها |
| Holding/Position | إسقاط كمية/تكلفة أداة من الأحداث المنشورة |
| Quote | لقطة سعر خارجية مؤرخة وليست حركة مالية |
| P&L | نتيجة مشتقة، ويجب الفصل بين realized وunrealized عند استكمال Lots |
| Net Worth | مجموع الأصول والالتزامات المقومة وفق سياسة تقييم معلنة |
| Alert | حالة تشغيلية أو تحليلية تتطلب مراجعة، وليست أمر تنفيذ |
| Approval | قرار مستقل يسمح لمسار مالي محدد بالانتقال إلى النشر |

## حدود الملكية والصلاحيات

تُستخدم أدوار `owner`, `advisor`, `editor`, `viewer` على مستوى Workspace، وتبقى صلاحية Super Admin العامة منفصلة عن ملكية البيانات المالية. يجب أن تكون صلاحيات القراءة والتعديل والنشر والاعتماد والتصدير والخزنة قابلة للاختبار كل واحدة على حدة.

الملف البرمجي المقابل لهذا العقد هو `shared/domainContracts.ts`. هذا الملف يثبت القيم والمصطلحات ولا يغير عمليات الدفتر أو يضيف أي أثر مالي.
